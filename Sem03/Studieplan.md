# B. Which are the specific learning goals you want to achieve?

Dit semester wil ik mij voornamelijk ontwikkelen op het gebied van **Realization, Design en Manage & Control**. Analysis blijft hierbij een belangrijke ondersteunende competentie: de technische oplossing moet uiteindelijk leiden tot kwalitatief goede en bruikbare analyses.

## 1. Een volledige open-source analytics-keten kunnen ontwerpen en realiseren

Ik wil leren om een volledige dataflow te ontwerpen en realiseren waarbij ik zoveel mogelijk gebruikmaak van open-source technologie.

Mijn gewenste keten is bijvoorbeeld:

**databron → data-ingestie → PostgreSQL → dbt → analyse → Apache Superset**

Ik wil hierbij niet alleen de afzonderlijke tools leren gebruiken, maar vooral begrijpen hoe de verschillende onderdelen met elkaar samenhangen en waarom bepaalde technische keuzes worden gemaakt.

## 2. Een complexe databron kunnen transformeren naar een relationeel analytisch model

Ik wil mij verdiepen in graph databases en onderzoeken hoe data uit een graph-georiënteerd model kan worden getransformeerd naar een relationeel model dat geschikt is voor analytische doeleinden.

Als uitgangspunt wil ik onderzoeken hoe ik bijvoorbeeld een graph database kan omvormen naar een relationeel datawarehouse in PostgreSQL.

Hierbij wil ik kunnen onderbouwen:

- welke informatie uit de bron behouden moet blijven;
- hoe relaties uit het graph-model vertaald kunnen worden;
- welke keuzes ik maak bij het relationele datamodel;
- waarom het uiteindelijke model geschikt is voor analyse.

## 3. dbt gebruiken voor reproduceerbare datatransformaties

Ik wil dbt leren gebruiken als transformatielaag binnen mijn dataflow.

Aan het einde van het semester wil ik kunnen aantonen dat ik:

- data kan transformeren met dbt;
- modellen logisch kan opbouwen;
- afhankelijkheden tussen modellen kan beheren;
- data quality tests kan toepassen;
- mijn transformaties kan documenteren;
- en mijn transformatielaag reproduceerbaar kan maken.

## 4. Data kwalitatief kunnen analyseren

Hoewel mijn primaire focus technisch is, blijft data-analyse een belangrijk onderdeel van mijn ontwikkeling.

Ik wil analyses efficiënter kunnen uitvoeren zonder dat dit ten koste gaat van de kwaliteit. Ik wil daarom beter worden in het bepalen welke analyse nodig is, welke statistische technieken passend zijn en hoe ik resultaten correct interpreteer.

Mijn doel is om niet alleen een technische dataflow te bouwen, maar ook te kunnen aantonen dat de data uiteindelijk leidt tot betrouwbare en bruikbare inzichten.

## 5. Een open-source BI-oplossing leren gebruiken

Ik wil Apache Superset verkennen en gebruiken als primaire dashboardoplossing voor mijn eigen product.

Ik wil hiermee onderzoeken hoe open-source BI zich verhoudt tot tools zoals Power BI en leren om bewuste keuzes te maken tussen verschillende technologieën.

Wanneer tijdgebrek of technische redenen het noodzakelijk maken, wil ik pragmatisch kunnen terugvallen op een closed-source oplossing. Mijn voorkeur blijft echter om zoveel mogelijk met een open-source stack te werken.

## 6. Mijn technische keuzes leren onderbouwen

Ik wil niet alleen leren *hoe* ik een technologie gebruik, maar ook *waarom* ik voor een bepaalde oplossing kies.

Bij technische keuzes wil ik daarom rekening houden met bijvoorbeeld:

- functionaliteit;
- complexiteit;
- onderhoudbaarheid;
- reproduceerbaarheid;
- datakwaliteit;
- beschikbare tijd;
- schaalbaarheid;
- en de behoeften van de gebruiker/business.

Hiermee wil ik groeien richting het niveau van een technisch georiënteerde BI/Data-professional en uiteindelijk Analytics Engineer.
